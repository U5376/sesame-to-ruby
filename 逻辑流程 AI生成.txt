1. EpubProcessor.__init__（初始化界面）
   - 功能：创建应用主界面并初始化所有组件
   - 详细流程：
     * 创建Tkinter主窗口，设置标题和图标(icon_base64)
     * 初始化转换选项配置(CFG)：
       - 傍点转ruby(class_name_var)
       - Ruby格式规格化(process_ruby_enabled)
       - 图片标签多看交互规格化(process_images_enabled)
       - Xhtml章节间合并(merge_xhtml_enabled + 分隔符/空行控制)
       - 删除自带Style并添加自定义样式表(delete_style_enabled)
       - 生成ncx并更新opf(generate_ncx_enabled + 偏移/强制偏移/补全后记/封面清理)
       - 转Epub2.0并删除nav.xhtml(convert_epub_version_enabled)
       - 转换图片(convert_images_var + 参数配置)
         - 自动旋转(override_count_var + override_skip_var + override_param_var)
         - override_skip_var 正则匹配支持 +强制包含 / !+排他模式
       - 语言标识(set_lang_enabled + 语言参数 + max_workers_var并发数)
       - 清理首部空行(remove_head_blank_enabled)
     * 初始化RegexManager组件：
       - 从config.ini加载用户自定义正则规则
       - 若无配置则创建默认规则(清理body/div/p标签样式等,含 DOM 标签结构改写规则)
       - 为每个规则添加可编辑的ToolTip说明(支持 fallback,不参与编辑与持久化)
     * 绑定规则保存按钮到主程序保存方法
     * 初始化批量转换按钮和单文件处理功能
     * 初始化辅助功能按钮：
       - 样式收集分析(show_class_list): 扫描EPUB中使用的CSS类,多线程解析/图片统计,支持拖拽/预览/搜索/搜索词条管理
       - 排除合并(show_exclude_dialog): 设置不合并的章节,支持正则追加分割章节,记忆 WinSize
       - 重置设置(reset_app_settings): 恢复默认配置,右键清理内存winsize
     * 加载应用设置(load_app_settings)
     * 窗口坐标大小记忆(WinSize类)

2. EpubProcessor.open_file_dialog（文件选择）
   - 用户选择输入EPUB文件
   - 支持拖拽epub到窗口

3. EpubProcessor.process_epub（核心处理流程）- 分为三个阶段
   - Phase 1: 结构级操作(单线程)
     1) 解压EPUB到临时目录(sesame_cache)
     2) 解析container.xml获取OPF路径(_get_opf_path)
     3) 图片转换(可选)：convert_epub_images
        - 扫描图片文件
        - 使用image_converter.exe转换格式
        - 自动旋转:超过阈值追加覆盖参数(-r -R),正则匹配支持 +强制包含 / !+排他模式
        - 更新HTML图片引用
        - 清理旧图片
        - 更新OPF媒体类型
     4) 处理OPF文件和样式表：process_opf_and_styles
        - 删除自带Style并添加自定义样式表
        - 设置语言标识(opf/head)
        - 规格化头部信息
     5) 生成ncx并更新opf：EpubNCXGenerator.generate_ncx
        - 基于NAV构建层级目录
        - 生成toc.ncx文件
     6) 修正ncx路径：EpubNCXGenerator.fix_ncx_paths
        - 目录偏移(检测文件不存在时自动-1修正)
        - 强制偏移(手动设置偏移值)
        - 补全后记(自动补全缺失のあとがき条目)
        - 封面/表纸条目清理:标题为封面/表纸但路径不在 spine(尤其 c0.xhtml)则删除文件,清理 manifest 与 guide 引用
     7) 转Epub2.0并删除nav.xhtml(可选)：EpubNCXGenerator.convert_to_epub2
        - 修改package声明为version="2.0"
        - 删除epub3.0的prefix属性
        - 移除nav.xhtml文件
     8) 正则追加、分割章节(可选)
        - 重新解析目录(_parse_toc)
        - 正则匹配追加新章节(_apply_regex_split)
          - 追加自动去重
          - 支持正则多捕获组拼合标题
          - 行首判定基于换行符 + 块级标签混合回退(空目录与单条目录兼容)
          - spt_ 序号动态调整防跳号
     9) 章节间合并(可选)：merge_xhtml_files
        - 解析OPF获取spine顺序和目录结构
        - 根据目录条目确定合并范围
        - 添加分隔符(双br标签夹hr标签)
        - 更新OPF,移除已合并文件引用
        - 支持排除特定目录条目

   - Phase 2: 单页内容级操作(多进程流水线)
     10) 多进程核心流水线处理(mp_process_single_file_pipeline)
         - 使用ProcessPoolExecutor并行处理(max_workers通过UI配置/Auto最高8)
         - psutil降级子进程优先级
         # 步骤 1: 首次 BS4 解析(在 soup 树上操作)
         a. DOM 标签结构改写:mp_rewrite_tags(soup, dom_rules)
            - 单标签匹配 DOM 条目改写:unwrap(拆包) / decompose(整块删除) / rename(改名,支持丢/保留/注入属性)
         b. 头部规格化:mp_normalize_xhtml_header(soup, lang_val, rel_css)
            - 规格化HTML属性(xmlns/xmlns:epub/xml:lang)
            - 重建Head信息(title/link)
         c. Ruby 格式规格化:mp_process_ruby(soup)
            - 合并连续的ruby标签
            - 提取<img>标签到Ruby外部
            - 合并多个<rt>内容
            - 清理多余的rb标签
         d. 傍点转ruby:mp_modify_html(soup, class_name)
            - 转换class指定的<span>/<em>为<ruby>
            - 创建rt标签并添加"・"
         # 步骤 2: 正则替换(在 content 文本层 re.sub)
         e. 按顺序应用每条正则规则;编写错误的正则 try/except 吞掉,防止整书崩溃
         # 步骤 3: 二次 BS4 解析(在 soup 树上操作,兜底纠错)
         f. mp_post_process_images(soup)
            - div/p包裹的图片规格化
            - svg和ops:switch标签兼容
            - 排除span跟gaiji标签
         g. mp_process_blank_lines(soup, ...)
            - 删除指定数量的空行
            - 限制连续空行的最大数量
            - 清理首部空行(remove_head_blank)
         # 步骤 4: XML 声明与保存
         h. 勾选样式修改:输出 html 标签内容 + 强制 XML 声明与 DOCTYPE
            - 未勾选:直接导出整个 soup

   - Phase 3: 收尾与重打包
     11) 重新打包EPUB

4. EpubNCXGenerator.generate_ncx（生成NCX）
   - 基于NAV构建层级目录(_parse_nav递归解析列表)
     * _parse_nav: 递归解析NAV结构构建层级
     * _create_ncx_content: 生成toc.ncx文件内容
   - 自动对照opf列表修正路径

5. EpubNCXGenerator.convert_to_epub2（版本转换）
   - 将EPUB3.0转换为EPUB2.0格式
     * 修改package声明为version="2.0"
     * 删除epub3.0的prefix属性
     * 移除nav.xhtml文件

6. EpubNCXGenerator.fix_ncx_paths（目录修正）
   - 偏移功能:最后一条目录文件不存在时自动-1修正
   - 强制偏移:手动设置偏移值,优先于自动偏移
   - 补全后记:自动补全 ncx/nav 缺失のあとがき条目
   - 封面/表纸条目清理:fix_ncx_paths 构造重建,处理标题为封面/表纸但路径不在 spine 的目录条目
     - 无则不补,孤儿 c0.xhtml 同步删除文件并清理 manifest/guide 引用

7. EpubProcessor.merge_xhtml_files（章节合并）
   - 解析OPF文件获取spine顺序和目录结构
   - 根据目录条目确定合并范围
   - 主文件保留,合并文件内容转移到主文件
   - 添加分隔符(双br标签夹hr标签)
   - 更新OPF文件,移除已合并文件的引用
   - 支持用户排除特定目录条目不合并

8. EpubProcessor.convert_epub_images（图片转换）
   - 扫描EPUB中所有图片文件
   - 使用image_converter.exe转换图片格式
   - 参数配置:-f格式 -q质量 -H/-W高宽 -s锐化 -A透明 -w线程 -m压缩等级
   - 自动旋转(-r -R)用于罫線图片
   - 正则匹配:默认排除(跳过命中项),支持 +强制包含 / !+排他模式
   - 更新HTML文件中的图片引用
   - 清理旧图片文件
   - 更新OPF清单中的媒体类型

9. EpubProcessor.batch_convert_epubs（批量转换）
   - 选择多个EPUB文件
   - 后台线程执行避免UI阻塞
   - 为每个文件创建输出目录(output)
   - 依次处理每个EPUB文件
   - 保存转换结果到输出目录
   - 记录转换状态和错误

10. 应用设置管理
   - 保存设置(save_app_settings)
     * 保存正则规则到config.ini
     * 保存应用配置选项(WinSize)
     * 搜索词条与 search_cfg_editor 窗口尺寸独立保存(save_search_box_only,不影响其他配置)
   - 加载设置(load_app_settings)
     * 从config.ini读取配置
     * 恢复界面状态
   - 重置设置(reset_app_settings)
     * 恢复默认选项值
     * 右键清理内存winsize
   - ini 配置空白处右键菜单支持"现有配置另存为新配置"(自动写入)

11. 辅助功能
   - 样式收集分析(show_class_list)
     * 扫描EPUB中使用的CSS类
     * 多线程动态分发解析(ThreadPoolExecutor)
     * 统计图片使用次数(xlink:href兼容)
     * 文件树浏览,支持拖入拖出导出导入
       - 拖出 0.5s 抖动延迟 + 双击预览拦截,防误触
       - 文件树右键支持复制文件名 / 含后缀文件名 / 完整路径
     * epub 文件树 HTML 节点分组:spine 正文(0)按阅读顺序在前,nav 及非 spine 文档(1)按文件名在后
     * 预览文件内容,支持正则匹配搜索
       - 多线程异步高亮 + 极速 line.col 定位,大文件不再卡顿
       - LRU 缓存(15 文件)防内存爆
       - 搜索词条支持自定义 + 历史(仅内存),可手动编辑保存
       - 样式筛选支持正则,词条同搜索框
       - 匹配 opacity 块灰字提示
     * 显示样式定义详情和实例,右键支持复制样式名
     * 支持临时样式编辑和追加
     * 可按字母/总量排序(扩展名解析用 os.path.splitext() 更精确)
   - 排除合并(show_exclude_dialog)
     * 解析EPUB目录结构
     * 提供GUI选择要排除合并的章节
     * 支持正则追加分割章节
     * 预览功能可实时查看内容
     * 右键管理排除列表
     * 窗口大小记忆(WinSize)
   - 正则管理(RegexManager)
     * 多配置文件(ini)管理
     * 右键复制/删除/重命名配置
     * 日志级别切换(debug/info)
     * 空白处右键"现有配置另存为新配置"
     * 正则条目右键支持上下添加新条目

12. 最终打包
   - 重新压缩为EPUB(zipfile.ZipFile写入)
   - 保留META-INF/container.xml结构
